# 🤖 AI CV Manager & Optimizer

A modern, AI-powered CV management platform built using **Google AI Studio** and **Gemini 1.5 Flash**. This application allows users to create, manage, and optimize their resumes using cutting-edge Generative AI.

## ✨ Features

- **AI Optimization Tips:** Get real-time, action-oriented suggestions to improve your resume content using Gemini.
- **Smart Parsing:** Automatically extract data from raw text or PDFs into structured resume sections.
- **Multiple Templates:** Switch between **Classic**, **Modern**, and **ATS-friendly** designs.
- **PDF Export:** Download your generated CV as a professional PDF.
- **Dashboard View:** Manage multiple CV versions from a single interface.

## 🛠️ Tech Stack

- **Frontend:** React.js, TypeScript, Vite
- **Styling:** Tailwind CSS / Custom CSS Templates
- **AI Engine:** Google Generative AI (Gemini API)
- **Deployment:** Vercel
